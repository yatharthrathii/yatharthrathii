## About

I build full-stack web and mobile applications, from the database and API layer up to the interface people actually use.

Most of my work has been on systems where being wrong costs something real: booking flows, payments, third-party integrations, authentication. That shaped how I write code. Types over comments, module boundaries that stay put, and error handling that tells you the truth instead of failing silently.

## How I work

- **The README does not claim what the code does not do.** Status is written down before features are announced, and updated when the code moves.
- **Pure logic stays pure.** Business rules live in modules with no framework imports, so they test in milliseconds and survive a framework change.
- **Errors are reported, not swallowed.** A startup failure says why and exits. A failed action tells the user. Silence is the bug.
